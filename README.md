# g-pay-app-demo
一个类似google pay样式的付款app demo

## 技术栈
- **框架**: Vue 3 + TypeScript
- **路由**: Vue Router 4
- **状态管理**: Pinia
- **构建工具**: Vite 6
- **CSS 框架**: Tailwind CSS 4
- **动画**: Motion Vue
- **图标**: Iconify

## 环境要求
- Node.js >= 18.x
- npm >= 9.x

## 安装依赖
```bash
npm install
```

## 调试（开发模式）
启动本地开发服务器，支持热更新（HMR）：
```bash
npm run dev
```
启动后在浏览器访问终端输出的地址（默认为 `http://localhost:5173`）。

## 构建
1. 先执行 TypeScript 类型检查，再进行生产构建：
```bash
npm run build
```
构建产物会输出到 `dist/` 目录。

## 预览构建产物
构建完成后，可在本地预览生产版本：
```bash
npm run preview
```
